# BillMat LLC Website

A responsive, static insurance education website for BillMat LLC. BillMat is an independent education platform and licensed agency partner; it is **not** an insurer or payment processor.

## Files

- `index.html` — homepage
- `insurance-partners/` — Progressive, Allstate, and Bristol West guides
- `css/style.css` — shared responsive styling
- `js/main.js` — mobile menu, header shadow, and smooth scrolling

## Local preview

From the project directory, run any static server, for example:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000/` in a browser. The site uses relative links so it works at the GitHub Pages project path `/billmat/`.

## GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main` and the repository root, then save. The project URL is:

`https://getlivesupport.github.io/billmat/`

## Content verification

The guide pages were written as educational material and include supplied contact information for verification. Phone numbers, addresses, payment availability, discounts, fees, posting times, hours, and grace periods can vary or change. Always confirm information on the official insurer website, policy documents, or current billing statement before sending money or changing coverage.

BillMat does not collect payment credentials, process payments, change policies, or represent Progressive, Allstate, Bristol West, or Farmers. External links go to official websites where available.
